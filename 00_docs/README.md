# GLITCH 1.0.2 + ALIGNMENT_GUARD v3.4.3 — suite layout and run order (consolidated layout)

Run everything: `python3 glitch_suite.py` (about a minute; `./run_all.sh` is a wrapper over it). One runner, one
summary table, one exit code, one `suite_report.json`. `--quick` skips the heavy cost/fuzz steps, `--full` enlarges
them, `--only 03,08` runs a subset, `--list` shows the steps, `--strict` makes a skipped optional dependency a failure.
No GNU `timeout` is needed; the runner uses subprocess timeouts, so it runs unchanged on macOS and Linux.
Optional dependencies (each gates only its own steps, which SKIP with the reason if absent):
`pip install fastapi httpx` (05a, 05b), `pip install numpy` (08c, 08d), `pip install pynacl` (08c).

Run one layer by hand: `cd` into its folder and use the command shown. Every entry-point script resolves its own
imports (path fallback to the sibling folders), so no PYTHONPATH is needed; the runner sets
`01_lib:02_canvas:05_deploy:06_bench:07_async` anyway, exactly as run_all.sh always did.

## What each layer is allowed to claim
- 00: the claim boundary (CONTRACT.md) and the one rule (DISCOVERIES.short.md). What is not done, who owns it and what would close it: OPEN_ITEMS.md (generated by `open_items.py`). What it would take to be credible to people who are not us, researched against the field's benchmarks, standards and publication routes: ROADMAP_TO_CREDIBLE.md. Nothing here is evidence; it says what evidence would be.
- 02–03: the specification is internally consistent and its scenarios execute (canvas + harness); the guard's contract properties hold (correctness); the contract survives composed failures, sensitivity verified only for the mutations actually exercised.
- 04: the demo shows detection and containment as two separate mechanisms on a canned transcript. It is a regression probe, not a safety claim.
- 05: the boundary between what the runtime guarantees and what the deployment must supply (five handoffs).
- 06: what the guarantees cost under a validated workload (never correctness).
- 07: experiments against the frozen baseline; evidence only, no mechanism is adopted here.
- 08: freezes what you control and produces evidence a third party can check; investigates nothing, attributes nothing.
- 09: whether the 0–5 ruler is a ruler. Nothing else in the suite substitutes for it.
- 10: history; claims nothing, executes nothing.
- The tooling that enforces the rules is itself under adversarial test (02c, 05b, 06b): the one rule applied to the suite.

## What is not in this folder and still gates production
The scorer's specificity levels have been checked against humans once, on a small sample (50 items, three raters; `00_docs/PROBES.md` L8 to L10, `09_study/`): agreement is moderate to substantial, level 3 is the soft spot, and a day-14 re-sitting is scheduled for 2026-10-10. What still gates production is a larger human study (three or more raters, 100 to 200 labelled items per failure mode) and a judge stronger than a local model.
